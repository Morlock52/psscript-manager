# PSScript Manager – Product Plan

## 1. Product Vision
Deliver a secure, collaborative PowerShell script management platform that lets teams store, organize, analyze, execute, and discuss scripts with strong governance, AI assistance, and enterprise-grade controls.

## 2. Target Users & Outcomes
- **Platform admins:** Configure org settings, SSO, roles, audit policies, and integrations.
- **Script authors:** Upload, version, categorize, execute, and improve scripts with AI feedback.
- **Reviewers/security teams:** Approve scripts, review risk/quality reports, monitor execution trails, and enforce policies.
- **Operators/support:** Run approved scripts safely, view run logs, and troubleshoot with analytics/voice/chat.

## 3. Core User Flows
1) **Onboarding & Auth**
   - SSO/JWT login, optional dev fallback.
   - Role selection (admin, maintainer, reviewer, operator, guest).
2) **Script lifecycle**
   - Create/upload (file or editor), attach metadata (name, description, tags, categories, owners), and version notes.
   - Server-side validation (syntax checks, size limits, approved file types), virus scan, and storage in object bucket.
   - AI analysis pipeline (security, quality, performance, complexity) with risk score and remediation suggestions.
   - Manual review/approval with comments and change requests.
   - Version history with diff view, rollback, and immutable audit trail.
3) **Execution & Scheduling**
   - Parameterized execution requests with environment/credential selection.
   - Policy checks (role, approvals, environment allow-list, time windows) before dispatch to isolated executor.
   - Real-time log/streamed output, structured result capture, and artifact download.
   - Optional recurring schedules and one-off maintenance windows.
4) **Search & Discovery**
   - Keyword and metadata search plus vector-based semantic search using embeddings.
   - Filters by category, tag, owner, risk level, approval state, last run, and dependency usage.
5) **Collaboration & Assistance**
   - Inline comments, mentions, and notifications on scripts and runs.
   - Chat assistant that answers questions about scripts, suggests fixes, and generates code snippets.
   - Voice input/output for hands-free queries and execution confirmation.
6) **Compliance & Observability**
   - Centralized audit log for auth, CRUD, approvals, executions, policy changes, and AI actions.
   - Health/status dashboard (service uptime, queue depth, error rates) and performance analytics.
   - Data retention settings and export (CSV/JSON) for logs, reports, and run outputs.

## 4. Feature Set
- **Script management:** CRUD, versioning, categories/taxonomies, tags, ownership, favorites, and sharing links.
- **AI-powered analysis:** Security linting, risky cmdlet detection, credential handling checks, least-privilege hints, performance optimizations, readability guidance, and autogenerated documentation.
- **Vector search:** Embeddings per script/version for similarity lookups and related-script recommendations.
- **Execution safety:** Sandboxed executor service, pre-flight dry runs, parameter validation, secret redaction, and safe output handling.
- **RBAC:** Role/permission matrix, organization/team scoping, and per-resource ACLs.
- **Integrations:** Webhooks, REST API, Git import/export, storage backends, and optional voice/AI providers (OpenAI/Anthropic).
- **Settings & keys:** User-level API keys, OpenAI key capture, feature flags, and environment templates.
- **UI/UX:** Dashboard (quick stats, alerts), script detail page (analysis, history, approvals, runs), execution console, settings, notifications, and admin panels.

## 5. Architecture Overview
- **Frontend (src/frontend):** React + TypeScript + Vite + Tailwind/MUI; uses React Query/Axios for API; supports realtime updates via WebSocket/SSE.
- **Backend API (src/backend):** Node.js + Express + TypeScript with Sequelize/pg + Redis; handles auth, script metadata, approvals, policy enforcement, and run orchestration.
- **AI Service (src/ai):** FastAPI + LangChain/OpenAI SDK; performs analysis, embeddings, chat, and voice pipelines; stores results and vectors in Postgres/pgvector.
- **Executor (src/executor):** Node service wrapping PowerShell in an isolated worker; receives signed requests from backend and streams logs back.
- **Data stores:** PostgreSQL (scripts, users, runs, approvals, embeddings, audit), Redis (sessions/cache/queues), object storage (script blobs, artifacts).
- **Edge/proxy:** Nginx fronting SPA, API, and AI routes; HTTPS termination; static asset serving.
- **Containers:** Docker/Docker Compose with dev/prod profiles; health checks; .env-driven config.

## 6. Data Model (high level)
- **Users:** id, org/team, roles, MFA/SSO identifiers, API keys, notification prefs.
- **Scripts:** id, owner, org/team, title, description, tags, categories, dependencies, approvals required.
- **Versions:** script_id, version number, file refs, hash, changelog, AI analysis results, risk score, embedding vector, status (draft/review/approved).
- **Runs:** script_version_id, requester, target environment, parameters, schedule info, status, output log refs, duration, return code.
- **Approvals/Reviews:** reviewer, decision, notes, timestamps, checklist results.
- **Audit events:** actor, action, resource, payload, ip/user-agent, correlation id.

## 7. Key APIs & Interactions
- **Auth:** login/refresh/logout, SSO callback, role assumption, session validation.
- **Scripts:** create/update/delete, upload endpoints, metadata edits, tag/category management, diff, approvals, publish/rollback.
- **Analysis:** trigger analysis, fetch reports, retrieve embeddings/related scripts, policy/risk summaries.
- **Execution:** start run, stream logs, cancel/pause, schedule, run history, artifact download.
- **Search:** text + vector search endpoints with filters and pagination.
- **Collaboration:** comments, mentions, notifications, and activity feeds.
- **Admin/Settings:** org/team management, RBAC policies, integrations, feature flags, audit export, health metrics.

## 8. Security & Compliance
- TLS everywhere; secrets via env/secrets manager; hashed passwords + MFA; JWT with rotation and short TTL.
- RBAC and attribute-based checks enforced on every API; least-privilege defaults; rate limiting and IP allow/deny lists.
- Validation/sanitization on uploads and inputs; AV scan on files; content-security-policy for frontend.
- Execution isolation with signed requests to executor, sandboxed PowerShell, redacted secrets in logs, and time/IO limits.
- Audit logging for auth, CRUD, approvals, runs, AI interactions; tamper-evident storage and retention policies.

## 9. Reliability & Operations
- Health checks for all services; structured logging with correlation IDs; metrics (latency, error rates, queue depth).
- Background workers for analysis, embedding generation, and scheduled runs with retry/backoff.
- Backups for Postgres/object storage; restore drills; migration/versioning strategy.
- Observability dashboards (APM, tracing) and alerting (threshold and anomaly-based).

## 10. Testing & Quality
- **Backend:** unit tests (business logic), integration tests (API + DB + Redis), contract tests for executor/AI, and security tests (authz, input validation).
- **Frontend:** unit/component tests, e2e flows (auth, upload, analysis, execution, chat), accessibility checks.
- **AI:** deterministic test prompts, toxicity/PII guardrails, and fallbacks/mocking when keys absent.
- **Performance:** load tests for uploads/search/execution streams; database index/EXPLAIN reviews.

## 11. Roadmap Milestones
1) **Stabilize auth & RBAC:** finalize Sequelize models, add SSO/MFA, tighten session handling.
2) **Harden execution path:** strict policy checks, sandboxing, signed requests, redaction, and audit coverage.
3) **AI excellence:** consistent analysis outputs, explainable risk scoring, vector search tuning, and offline/mock modes.
4) **Collaboration polish:** approvals, comments, notifications, and documentation generation.
5) **Ops & reliability:** monitoring, alerting, backups, rollout strategy, and blue/green deploys.
6) **Enterprise readiness:** org/team scoping, webhooks/API tokens, compliance exports, and custom retention rules.

## 12. Success Metrics
- Time to approve new scripts; reduction in production incidents after AI recommendations.
- Mean time to detect/remediate risky scripts; execution success rate and latency.
- User adoption: active authors/reviewers/operators; chat/voice engagement; search success rate.
- Compliance posture: audit completeness, SSO/MFA coverage, and policy violation trends.
